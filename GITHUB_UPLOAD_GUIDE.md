# GitHub Upload Guide

## 1. Create repository
On GitHub, create a new **Public** repository named:
`northstar-support-deflection-mvp`

## 2. Upload the project
Upload all files from this project folder. Do not upload only `index.html`; the `pages`, `css`, `js`, and `data` folders are required.

The repository root must contain:
- `index.html`
- `README.md`
- `pages/`
- `css/`
- `js/`
- `data/`

## 3. Commit
Commit with a message such as:
`Add Northstar Support Deflection MVP`

## 4. Enable Pages
Go to:
**Settings → Pages**

Under **Build and deployment**:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Click **Save**.

## 5. Test the published site
The project site normally follows:
`https://YOUR-GITHUB-USERNAME.github.io/northstar-support-deflection-mvp/`

Test the home page first, then:
- Order Status
- Delivery Progress
- Returns & Refunds
- Return Instructions
- Return Status
- Stock Availability
- Alternatives
- Stock Notification
- Human Support

## 6. Do not change the folder structure
Relative links are used throughout the prototype. Moving files or renaming folders after upload can break navigation.
