Return Instructions

Complete the steps below before creating your demonstration return request.

Prepare the product

Place the product securely in suitable packaging. Where applicable, include the original packaging and accessories.

Check the item

Make sure the product you are returning corresponds to the item listed on your order.

Prepare your return information

Keep your order number available. A return reference will be generated after you submit the request.

Package the item

Securely seal the package and remove or cover previous shipping labels.

Create the return request

Select the button below. The demonstration system will create a return reference and show the next status.

Keep the confirmation

Keep your return reference until the demonstration return has been received and the refund process is completed.

Important: This prototype demonstrates the customer journey. It does not generate a real carrier label, collect a payment, or contact a live return service.
